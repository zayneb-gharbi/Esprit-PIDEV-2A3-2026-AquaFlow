AQUAFLOW - CORRECTION DE L'APPEL FACEBOOK

Ce petit complement s'applique au dossier amir deja installe.

1. Extraire TOUT le ZIP dans un dossier de Telechargements.
2. Ouvrir REPARER_FACEBOOK_WINDOWS.bat.
3. Choisir DEMARRER_HTTPS_WINDOWS.bat dans le dossier amir habituel.
4. Attendre le message "Correction installee".
5. Dans la fenetre du SERVEUR HTTPS, appuyer sur Entree pour l'arreter.
6. Relancer DEMARRER_HTTPS_WINDOWS.bat depuis le projet habituel.
7. Ouvrir https://127.0.0.1:8443/amir/public/index.php?page=login
8. Se reconnecter avec Google, puis Securite > Associer Facebook.
   Effectuer l'association dans les cinq minutes apres la connexion.
9. Si l'association reussit : se deconnecter d'AquaFlow et tester le
   bouton Facebook. Si la 2FA est active, entrer le code Authenticator.

Si une erreur apparait, envoyer UNIQUEMENT le nouveau texte rouge.
Ne pas actualiser l'ancienne page de retour : commencer une nouvelle
connexion depuis AquaFlow pour obtenir un nouveau code Facebook.

Le correctif remplace seulement controllers/SocialController.php.
Il verifie la version actuelle avant de remplacer et conserve une
sauvegarde privee dans var/facebook-updates. Une version differente
n'est pas remplacee : envoyer le message pour verifier les fichiers.

L'appel Facebook qui echange le code utilise maintenant GET, comme
dans le guide officiel Meta. L'appel Google reste en POST avec PKCE.
Les controles de securite, la verification TLS et la 2FA sont conserves.
Le diagnostic donne des indications sans afficher les cles, codes ou
jetons, ni le texte brut d'une reponse externe.

Le code 1 de Meta est une erreur generale : il peut notamment etre
temporaire. Ce correctif aligne l'appel sur la documentation, mais
un nouvel essai reel reste necessaire pour valider Facebook.
158 verifications automatiques passent, avec fournisseurs simules.
Le nouvel installateur Windows doit etre execute sur le PC du projet.

config/local.php, les comptes, la base et la cle 2FA restent conserves.
Les fichiers du groupe ne sont pas modifies. Aucun push Git n'est fait.

Sources :
https://developers.facebook.com/docs/facebook-login/guides/advanced/manual-flow/
https://developers.facebook.com/docs/graph-api/guides/error-handling
